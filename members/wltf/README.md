## 第一次 Git 实验总结

1. `git add` 的作用是：把工作区里文件的改动添加到暂存区，告诉 Git 哪些改动要放进下一次提交，此时还没有真正保存版本。
2. `git commit` 的作用是：把暂存区的内容正式提交到本地仓库，生成一个带提交信息的版本快照，之后可以查看或回溯到这次提交。
3. 本次实验中 `git restore notes.md` 的作用是：丢弃 notes.md 未提交的改动，把它恢复到最近一次提交的版本，也就是撤销对这个文件的修改。
4. `commit` 与 `push` 的区别是：commit 只是提交到本地仓库，只有自己电脑上能看到；push 是把本地提交推送到远程仓库，推送后别人才能看到。
